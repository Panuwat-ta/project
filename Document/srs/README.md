# เอกสาร Requirements และ SRS ฉบับปัจจุบัน

โฟลเดอร์นี้เป็นแหล่งอ้างอิงหลัก (canonical source) สำหรับ Requirement Candidates, Software Requirements Specification (SRS), Requirement Traceability และ Full Traceability Matrix ของ ScamGuard

## เอกสารปัจจุบัน

- `04_Requirement_Candidates.md` — Requirement Candidates (RC)
- `05_Software_Requirement_Specification.md` — SRS, FR, NFR และ Acceptance Criteria
- `06_Requirement_Traceability.md` — Requirement Traceability Matrix
- `07_Appendix_A_Full_Traceability_Matrix.md` — เมทริกซ์การสืบย้อนความต้องการฉบับเต็ม

## กติกาการแก้ไข

- แก้ไข Requirement/SRS ฉบับปัจจุบันในโฟลเดอร์นี้เท่านั้น
- เมื่อมีการเปลี่ยนแปลงที่ต้องเก็บหลักฐาน ให้สร้างรายการอธิบายการเปลี่ยนแปลงพร้อมวันที่ใน `../docs/` และอ้างถึงไฟล์/ส่วนที่เปลี่ยน
- ห้ามสร้างสำเนา SRS ฉบับปัจจุบันใน `Document/log_docs/` โดยไม่มีวันที่หรือสถานะ snapshot

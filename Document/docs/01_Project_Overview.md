## 2. Problem Statement

### 2.1 Problem Description

ในยุกปัจจุบัน การหลอกลวงทางไซเบอร์ (Cybercrime) โดยเฉพาะการใช้รูปภาพที่ถูกตัดต่อหรือปลอมแปลงเพื่อหลอกลวงประชาชนทั่วไป มีแนวโน้มเพิ่มสูงขึ้นอย่างต่อเนื่อง รูปแบบการหลอกลวงที่พบบ่อย ได้แก่:

1. **สลิปโอนเงินปลอม** — การแก้ไขรายละเอียดจำนวนเงิน ชื่อบัญชี หรือวันที่-เวลาในสลิปการโอนเงิน เพื่อหลอกให้ผู้ขายสินค้าส่งสินค้าโดยไม่ได้รับเงินจริง
2. **รูปโปรไฟล์หลอกลวง (Romance Scam)** — การใช้รูปภาพบุคคลอื่น (เช่น ดารา นางแบบ) หรือรูปภาพที่ถูกสร้างด้วยปัญญาประดิษฐ์ (AI-Generated Images) เพื่อสร้างความน่าเชื่อถือในการหลอกลงทุนหรือหลอกโอนเงิน
3. **ภาพโฆษณาหลอกลวง** — การใช้ภาพที่ตัดต่อหรือภาพที่คัดลอกมาจากแหล่งอื่นเพื่อโฆษณาสินค้าหรือบริการที่ไม่มีอยู่จริง

### 2.2 Problem Context

- **Who is affected:** ประชาชนทั่วไปที่ใช้งานสื่อสังคมออนไลน์ ซื้อขายสินค้าออนไลน์ หรือทำธุรกรรมทางการเงินผ่านช่องทางดิจิทัล โดยเฉพาะผู้ที่ไม่มีความรู้ทางเทคนิคในการตรวจสอบความถูกต้องของภาพถ่าย
- **Where it occurs:** เกิดขึ้นบนแพลตฟอร์มสื่อสังคมออนไลน์ แอปพลิเคชันซื้อขายสินค้า และช่องทางการสื่อสารออนไลน์ต่างๆ
- **Impact:** ความสูญเสียทางการเงิน ความเสียหายทางจิตใจ การสูญเสียความไว้วางใจในการทำธุรกรรมออนไลน์ และการเพิ่มขึ้นของอาชญากรรมทางไซเบอร์

### 2.3 Current Limitations

วิธีการตรวจสอบภาพในปัจจุบันมีข้อจำกัดดังนี้:

1. **การตรวจสอบด้วยสายตา** — ผู้ใช้ทั่วไปไม่สามารถสังเกตเห็นการตัดต่อในระดับพิกเซลได้ด้วยตาเปล่า โดยเฉพาะเมื่อมิจฉาชีพใช้เทคนิคการตัดต่อที่ซับซ้อน
2. **เครื่องมือตรวจสอบที่ซับซ้อน** — ซอฟต์แวร์นิติวิทยาศาสตร์ดิจิทัล (Digital Forensics Tools) มีความซับซ้อนสูง ต้องใช้ความรู้เชิงเทคนิคและใช้งานบนคอมพิวเตอร์เท่านั้น
3. **ไม่สามารถตรวจจับภาพ AI-Generated** — วิธีการดั้งเดิมไม่สามารถแยกแยะภาพที่ถูกสร้างด้วย Generative AI (เช่น Stable Diffusion, Midjourney, DALL-E) ซึ่งมีคุณภาพสูงและดูสมจริง
4. **การค้นหาแหล่งที่มาด้วยตนเอง** — การใช้ Google Images หรือ Reverse Image Search ต้องทำด้วยตนเองทีละขั้นตอน ใช้เวลานาน และต้องตีความผลลัพธ์เอง

### 2.4 Motivation

ความจำเป็นในการพัฒนาระบบ ScamGuard เกิดจาก:

1. **ความต้องการเครื่องมือที่เข้าถึงง่าย** — ผู้ใช้ทั่วไปต้องการเครื่องมือที่ใช้งานได้บนสมาร์ทโฟน ไม่ต้องใช้ความรู้ทางเทคนิค และให้ผลลัพธ์ได้อย่างรวดเร็ว
2. **การวิเคราะห์แบบหลายมิติ** — การตรวจสอบเพียงมิติเดียวไม่เพียงพอ ต้องรวมการวิเคราะห์ข้อความ (OCR + NLP), การวิเคราะห์ภาพ (Visual Forensics + AI Detection), และการตรวจสอบแหล่งที่มา (Reverse Image Search)
3. **ความโปร่งใสและความเข้าใจได้** — ผู้ใช้ต้องเข้าใจว่าระบบตัดสินใจอย่างไร ดังนั้นจึงต้องมีการอธิบายผลด้วย Explainable AI (XAI) ผ่านแผนที่ความร้อน (Grad-CAM Heatmap)
4. **การสร้างชุดข้อมูลบริบทไทย** — การรวบรวมภาพหลอกลวงที่เกิดขึ้นจริงในประเทศไทยเพื่อนำมาพัฒนาและปรับปรุงโมเดล AI ให้เหมาะสมกับบริบทท้องถิ่น

## 3. Objectives

### OBJ-01 — เพื่อพัฒนาแอปพลิเคชันบนอุปกรณ์เคลื่อนที่สำหรับคัดกรองรูปภาพที่มีความเสี่ยง

**Description:**  
พัฒนาแอปพลิเคชันบนมือถือแบบ Cross-Platform (ด้วย Flutter) ที่ช่วยให้ผู้ใช้งานทั่วไปสามารถเลือกและอัปโหลดรูปภาพที่ต้องสงสัย (เช่น สลิปโอนเงิน, ภาพโปรไฟล์บุคคล) เพื่อส่งตรวจสอบความเสี่ยงของการปลอมแปลงและการหลอกลวงได้สะดวกรวดเร็ว

**Success Criteria:**
- แอปพลิเคชันรองรับการทำงานบน Android อย่างเต็มประสิทธิภาพ
- ผู้ใช้สามารถเลือกภาพจากคลังภาพ (Gallery) และอัปโหลดเข้าสู่ระบบได้
- ผู้ใช้สามารถครอบตัดรูปภาพ (Crop) ก่อนส่งตรวจสอบได้
- แอปแสดงผลความเสี่ยงในรูปแบบที่เข้าใจง่าย พร้อมแผนที่ความร้อน (Heatmap)

### OBJ-02 — เพื่อประยุกต์ใช้เทคโนโลยี Deep Learning ในการตรวจสอบการแก้ไขและภาพสังเคราะห์ปัญญาประดิษฐ์

**Description:**  
พัฒนาและฝึกสอนโมเดลปัญญาประดิษฐ์เชิงลึก (Deep Learning) ในการประเมินร่องรอยดัดแปลงภาพในระดับพิกเซลด้วยเทคนิค ELA (Error Level Analysis) เพื่อตรวจจับการสอดแทรกรูปภาพ (Splicing) หรือคัดลอกจุดภาพ (Copy-Move) และคัดกรองรูปภาพที่ถูกสร้างขึ้นด้วยปัญญาประดิษฐ์ (AI-Generated Image)

**Success Criteria:**
- โมเดล AI มีความแม่นยำ (Accuracy) และค่า F1-Score ≥ 85% ในชุดข้อมูลทดสอบ
- โมเดลสามารถตรวจจับการตัดต่อระดับพิกเซล (Image Forgery) ได้
- โมเดลสามารถแยกแยะภาพที่สร้างจาก Generative AI (AI-Generated Detection) ได้
- ระบบสร้างแผนที่ความร้อน (Grad-CAM Heatmap) เพื่ออธิบายผลการตัดสินใจของโมเดล

### OBJ-03 — เพื่อพัฒนาระบบวิเคราะห์ความเสี่ยงแบบบูรณาการ (Multi-layer Analysis)

**Description:**  
พัฒนาระบบประมวลผลกลางหลังบ้าน (FastAPI) ที่ผสมผสานการวิเคราะห์ข้อมูลเมทาดาตาแฝง (Metadata), การสกัดและตรวจจับข้อความอันตราย (OCR & NLP) และการสืบค้นหาแหล่งที่มาของรูปภาพย้อนกลับ (Reverse Image Search) ควบคู่กับผลวิเคราะห์ของโมเดล AI เพื่อคำนวณออกมาเป็นคะแนนความเสี่ยงรวม (Weighted Risk Score)

**Success Criteria:**
- ระบบสามารถสกัดข้อมูล EXIF/Metadata จากรูปภาพได้
- ระบบสามารถสกัดข้อความจากรูปภาพด้วย OCR (ภาษาไทยและอังกฤษ) ได้
- ระบบสามารถตรวจจับคำสำคัญหลอกลวง (Scam Keywords) ได้
- ระบบสามารถค้นหาแหล่งที่มาของภาพผ่าน Reverse Image Search ได้
- ระบบคำนวณคะแนนความเสี่ยงรวมตามสูตร: Risk Score = (S_text × 0.25) + (S_visual × 0.45) + (S_source × 0.30)

**Related Stakeholders:** ST01, ST02

### OBJ-04 — เพื่อทดสอบและประเมินประสิทธิภาพของระบบ รวมถึงความพึงพอใจของกลุ่มผู้ใช้เป้าหมาย

**Description:**  
ดำเนินการทดสอบการยอมรับของระบบจากผู้ใช้ (UAT) ประเมินความเร็วในการตอบสนอง และความง่ายในการเข้าใจผลการสแกนผ่านการนำเสนอแผนที่ความร้อน (Grad-CAM Heatmap) ตามแนวคิดปัญญาประดิษฐ์ที่อธิบายได้ (Explainable AI - XAI)

**Success Criteria:**
- ความเร็วในการตอบสนอง (Cache Hit) ≤ 3 วินาที
- ความเร็วในการวิเคราะห์ใหม่ทั้งหมด (New Analysis) ≤ 15 วินาทีต่อภาพ (median)
- ระบบมีความพร้อมใช้งาน (Uptime) ≥ 99.5%
- ผู้ใช้ ≥ 80% สามารถเข้าใจแผนที่ความร้อน (Heatmap) โดยไม่ต้องมีพื้นฐานทางเทคนิค
- คะแนนความพึงพอใจโดยรวม (Likert Scale 5 ระดับ) ≥ 4.00 คะแนน

**Related Stakeholders:** ST01, ST02, ST03

### ST02 — ผู้ดูแลระบบ

**Person:** นาย พีรพล อนุตรโสตถิ์  
**Organization:** ศูนย์ชัวร์ก่อนแชร์ อสมท  
**Type:** System Administrator / Project Stakeholder  
**Role:** ผู้ดูแลระบบและผู้เกี่ยวข้องจากศูนย์ชัวร์ก่อนแชร์ อสมท

**Needs:**
- ต้องการระบบแดชบอร์ดสำหรับติดตามสถิติการใช้งานและประสิทธิภาพของระบบ
- ต้องการเครื่องมือจัดการผู้ใช้งาน (CRUD Operations) และกำหนดสิทธิ์การเข้าถึง (RBAC)
- ต้องการตรวจสอบและพิจารณารูปภาพที่ผู้ใช้รายงานว่าเป็นภาพหลอกลวง
- ต้องการอัปเดตโมเดล AI และจัดการชุดข้อมูล (Dataset Management)
- ต้องการระบบบันทึกการดำเนินการ (Audit Logs) เพื่อความโปร่งใสและความมั่นคงปลอดภัย

**Characteristics:**
- มีความเข้าใจด้านเทคนิคและระบบซอฟต์แวร์ระดับปานกลางถึงสูง
- รับผิดชอบดูแลความมั่นคงปลอดภัยและคุณภาพข้อมูลของระบบ
- อาจเป็นนักวิจัยหรือผู้เชี่ยวชาญด้านการตรวจสอบภาพหลอกลวง

## 6. Expected Benefits

### 6.1 ลดความสูญเสียจากภัยคุกคามทางไซเบอร์

ช่วยป้องกันประชาชนทั่วไปจากการตกเป็นเหยื่อของการหลอกโอนเงินด้วยสลิปปลอม และป้องกันการหลอกลวงผ่านบัญชีอวตาร (Romance Scam) ที่ใช้ภาพดัดแปลงหรือภาพสังเคราะห์จาก AI ลดความสูญเสียทางการเงินและความเสียหายทางจิตใจ

### 6.2 สร้างความตระหนักรู้และความเข้าใจเชิงลึกแก่สังคม

ผู้ใช้งานทั่วไปมีความรู้เท่าทันสื่อดิจิทัลเพิ่มขึ้นจากระบบ Explainable AI (XAI) ที่อธิบายเหตุผลของการวิเคราะห์จุดพิกเซลที่ผิดปกติ ช่วยลดความระแวงหรือความตื่นตระหนกที่ไม่มีที่มา และเพิ่มความมั่นใจในการตัดสินใจ

### 6.3 ประโยชน์ทางการวิจัยและการพัฒนาชุดข้อมูล (Dataset)

ได้รับชุดข้อมูลภาพสแกมเมอร์ในประเทศไทย (Thai-Context Scam Dataset) ที่จัดหมวดหมู่โดยแอดมินจากการรายงานของผู้ใช้งานจริง ซึ่งสามารถนำไปใช้ในการฝึกสอนและพัฒนาความรู้ทางปัญญาประดิษฐ์ในระดับประเทศต่อไปได้

**Evidence:**
- File: project/Document/objective.md
- Section: ประโยชน์ที่คาดว่าจะได้รับ (Expected Benefits)
- Paraphrase: ระบุประโยชน์ 3 ด้านหลัก คือ ลดความสูญเสีย สร้างความตระหนักรู้ และพัฒนาชุดข้อมูลวิจัย

## admin-portal/ (React)

- **PORTAL-H1 (High, A07)**: รหัสผ่าน default อ่อนใน `admin-portal/.env:58` (`VITE_*` ถูก bake ลง client bundle;
  gate `DEV` ช่วยแค่ production build) — บรรเทา: `.env` ถูก gitignore, `.env.example` เว้นว่างถูก —
  แนะนำ: ลบรหัสออกจาก `.env`, เปลี่ยนรหัส, ห้ามใช้กับ backend จริง
- **PORTAL-M1 (Medium, A02)**: access token ใน WS query string (`src/lib/api.js:283-286`) — หลุดเข้า logs/history ได้; ควรใช้ subprotocol/ticket สั้น
- **PORTAL-M2 (Medium, A01)**: `ProtectedRoute` (`App.jsx:19-61`) เช็กแค่มี token ไม่เช็ก role (defense-in-depth; สิทธิ์จริงอยู่ backend)
- **Low**: `user` (ไม่มี token) ใน localStorage (`api.js:20,32,38`); `console.error` 12 จุดเห็นผ่าน devtools; http เฉพาะ loopback dev
- **OK**: ไม่มี XSS sink (`dangerouslySetInnerHTML`/`eval` = 0 hits), ไม่มี secret ใน `src/`, token ใน memory, refresh ผ่าน httpOnly cookie, error generic, deps ปัจจุบัน (React 19, Vite 8)

## scam_image_mobile/ (Flutter)

- **MOBILE-H1 (High, A02)**: cleartext ทั้งเส้น — `AndroidManifest.xml:6` `usesCleartextTraffic="true"` +
  `.env:5` `API_BASE_URL=http://10.210.11.70...` + `.env` ถูก bundle ใน APK (`pubspec.yaml:63`) —
  token/รหัสผ่าน/รูปดักบน LAN ได้; ต้องเปลี่ยนเป็น https + ตัด flag + เลิก bundle `.env`
- **MOBILE-M1 (Medium, A02)**: ไม่มี certificate pinning (`dio_client.dart:12-30`)
- **MOBILE-M2 (Medium, A05)**: release เซ็นด้วย debug key + `applicationId com.example...` (`build.gradle.kts:19,32`)
- **MOBILE-M3 (Medium, A05)**: ไม่ตั้ง backup rules + `scamguard.db` (ประวัติสแกน) plaintext ผ่าน sqflite
- **Low**: `hasValidToken` ไม่เช็ก expiry (`auth_local_datasource.dart:36-39`); validation/nโยบายรหัสไม่สม่ำเสมอ (login 6 vs register 8 ตัวอักษร — server ต้องตัดสิน); `parseUrl` ยอม URL ใด ๆ จาก server
- **OK**: ไม่มี hardcoded secrets, ไม่มี WebView, token ใน `flutter_secure_storage`, SQL parameterized, logout ล้างจริง, iOS ไม่มี ATS exception, `LogInterceptor` ไม่ log body

## prototype/ (UI mockup — ไม่มี backend จริง)

- ไม่มี XSS sink, ไม่มี secret, มีแค่ `fetch("/api/scan")` จุดเดียว (`App.tsx:67`); auth เป็น mock
- นโยบายรหัสใน mock ไม่ตรงกัน (Login 6 vs Register 8) — ย้ำว่า prototype ไม่ใช่ spec; server คือตัวตัดสิน

## ลำดับแก้แนะนำ

3. MOBILE-M2/M3 (signing + backup rules), PORTAL-M1 (WS auth)
4. S-GAP-3, PORTAL-M2, pinning, S-GAP-2 (ยืนค่า deploy)

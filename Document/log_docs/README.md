# Document History and Audit Archive

โฟลเดอร์นี้เก็บประวัติ เอกสาร audit การตัดสินใจ และ baseline snapshot ของโครงการ ScamGuard ไม่ใช่แหล่งอ้างอิง Requirement/SRS ฉบับปัจจุบัน

## Source of Truth

เอกสาร Requirement/SRS ปัจจุบันอยู่ที่ [`../srs/README.md`](../srs/README.md) การอ้างอิง FR, NFR, Acceptance Criteria และ traceability ใหม่ต้องชี้ไปที่ `Document/srs/`

## เนื้อหาที่เก็บไว้

- `01_` ถึง `07_` — baseline snapshot และเอกสารออกแบบ/ข้อกำหนดที่คงไว้เพื่ออ้างอิงประวัติ
- ไฟล์ที่ลงวันที่ เช่น `09_QA_Audit_2026-09-13.md` — ผลตรวจ audit หรือรายงานเฉพาะรอบ

## กติกาการบันทึกประวัติ

- ห้ามแก้ไขไฟล์ history ที่ปิดรอบแล้ว; หากต้องแก้หรือเพิ่มข้อมูล ให้สร้างไฟล์ใหม่พร้อมวันที่ในชื่อไฟล์
- ทุกไฟล์ history ใหม่ต้องระบุวันที่, เอกสาร canonical ที่เกี่ยวข้อง, สรุปสิ่งที่เปลี่ยน, เหตุผล และหลักฐานการตรวจสอบ
- ห้ามคัดลอก SRS ฉบับปัจจุบันมาวางซ้ำโดยไม่ระบุว่าเป็น snapshot และวันที่อ้างอิง

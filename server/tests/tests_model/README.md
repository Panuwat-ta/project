# รายงานผลการทดสอบเปรียบเทียบโมเดล SegFormer ทั้ง 5 เวอร์ชัน (v1.0.0 ถึง v1.0.4)

โฟลเดอร์นี้รวบรวมไฟล์รูปภาพต้นฉบับและผลลัพธ์ภาพ Heatmap จากการทดสอบเปรียบเทียบโมเดล SegFormer ตั้งแต่เวอร์ชัน `v1.0.0` ถึง `v1.0.4` บนภาพทดสอบจริง 2 ภาพ

---

## 1. ข้อมูลภาพทดสอบ (Test Images)
- **ภาพที่ 1 (`-1`):** ภาพนกผสมกวางจาก Worth1000 (Complex Photomontage Splicing)
- **ภาพที่ 2 (`-2`):** ภาพคนวิ่งหนีจระเข้ (Photoshop Human Splicing บนพื้นหลังทุ่งหญ้า)

---

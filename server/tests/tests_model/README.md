# คลังภาพสาธิตเชิงคุณภาพ SegFormer (v1.0.0 ถึง v1.0.4)

> ภาพสาธิต n=2 นี้ไม่มี ground-truth mask และไม่ใช่ test set มาตรฐาน จึงห้ามใช้จัดอันดับโมเดลหรืออ้างเป็น accuracy ผลเชิงปริมาณทางการอยู่ที่ `model/segformer/tests_model/report/reportmodel.md`

โฟลเดอร์นี้เป็น archive ของรูปต้นฉบับและ Heatmap สำหรับตรวจดูพฤติกรรม SegFormer ตั้งแต่ `v1.0.0` ถึง `v1.0.4` บนภาพเลือกมาสาธิต 2 ภาพ

---

## 1. ข้อมูลภาพทดสอบ (Test Images)
- **ภาพที่ 1 (`-1`):** ภาพนกผสมกวางจาก Worth1000 (Complex Photomontage Splicing)
- **ภาพที่ 2 (`-2`):** ภาพคนวิ่งหนีจระเข้ (Photoshop Human Splicing บนพื้นหลังทุ่งหญ้า)

## 4. ตัวชี้วัดทางการ

| Metric | เกณฑ์ผ่าน | ค่าปัจจุบัน | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| SegFormer mDice (locked common test) | ≥85% (NFR-AI-01) | v1.0.5 = 95.25%, v1.0.4 = 88.74% | Dataset `scamguard-locked-multisource-test-v1`; ดู manifest และรายงานหลัก |
| MaxProb ภาพสาธิตที่ 1/2 | แจ้งเพื่อประกอบเท่านั้น (ไม่มี threshold) | ดูตาราง §2 | ไม่ใช่ metric ตัดสิน |

วิธีทำซ้ำผลทางการให้ใช้ `model/segformer/tests_model/evaluation_manifest.json` และ `model/segformer/tests_model/report/plot_training.py --clean` ตาม README ในโฟลเดอร์นั้น จำนวนภาพจริงของ locked test set ยังไม่ได้บันทึก จึงรายงานเพียง 2,504 batches และห้ามอนุมานจำนวนภาพจาก batch size

ภาพในโฟลเดอร์นี้เป็นต้นฉบับ PNG และ heatmap JPG (ภาพที่ 1 Worth1000 photomontage, ภาพที่ 2 Photoshop splicing) ใช้สาธิตภายในเท่านั้น



## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key

> **ขอบเขต:** โฟลเดอร์ `prototype/` เป็นต้นแบบทดลองภายในเท่านั้น (throwaway) — **ห้ามใช้ใน Production**; ระบบจริงเป็น On-Premise 100% (ไม่ออกคลาวด์ภายนอก, สอดคล้อง PDPA) ห้าม commit ไฟล์ `.env.local` หรือคีย์จริงลง repo เด็ดขาด
3. Run the app:
   `npm run dev`

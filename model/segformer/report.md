# รายงานผลการเปรียบเทียบประสิทธิภาพโมเดล SegFormer

**โปรเจค**: แอปตรวจสอบรูปภาพตัดต่อที่ถูกนำมาหลอกลวง (Scam Image Detection)

รายงานฉบับนี้เป็นการสรุปผลการเปรียบเทียบประสิทธิภาพของโมเดล SegFormer จำนวน 2 เวอร์ชัน ได้แก่ `segformer_v1.0.0` และ `segformer_v2.0.0` จากการประเมินผลผ่านค่า mIoU (Mean Intersection over Union) ซึ่งเป็นมาตรวัดหลักที่ใช้ในการทดสอบความแม่นยำของโมเดล

จากการตรวจสอบไฟล์บันทึกการทำงาน (Log) ของทั้งสองโมเดล พบว่า **segformer_v2.0.0 มีประสิทธิภาพที่สูงกว่าอย่างเห็นได้ชัด** โดยมีรายละเอียดดังนี้:

### 1. โมเดล segformer_v1.0.0
- **ไฟล์ Log**: `work_dirs/segformer_v1.0.0/20260715_075535/20260715_075535.log`
- **mIoU สูงสุด**: **56.50%**
- **จุดที่บันทึกโมเดล (Iteration)**: 128,000

### 2. โมเดล segformer_v2.0.0
- **ไฟล์ Log**: `work_dirs/segformer_v2.0.0/20260717_042853/20260717_042853.log`

- **จุดที่บันทึกโมเดล (Iteration)**: 144,000

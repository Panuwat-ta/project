Det-Head — ผล test-case รายเวอร์ชัน

ทุกเวอร์ชันถูกรันใหม่พร้อมกันด้วย eval_det_diagnostics.py บนภาพชุดเดียวกัน (20 heads, seg backbone /home/panuwat/project/model/segformer/work_dirs/v1.0.6/best_mIoU_iter_195000.pth, threshold 0.5) — ไม่ใช้ผลเก่าจากคนละรอบมาปนกัน

ขอบเขตของข้อมูล

  • testcases 165 ภาพ: with_mask 105 ภาพ (authentic 15 ภาพ label 0, อีก 6 หมวด 90 ภาพ label 1) บวก pairs 60 ภาพ (originals 30 ภาพ label 0, manipulated 30 ภาพ label 1) รวมภาพจริง 45 ภาพ และภาพดัดแปลง 120 ภาพ ไฟล์ทั้งหมดอยู่ใน /home/panuwat/Pictures/Test-Cases
  • camera9: ภาพถ่ายจากกล้องมือถือจริง 9 ภาพ label 0 ทั้งหมด — specificity ที่นี่คืออัตราที่ไม่ false alarm
  • chatshot2: แชต/สกรีนช็อต 2 ภาพ label 0 ทั้งหมด n เล็กมาก ใช้ดูแนวโน้มเท่านั้น ห้ามใช้ตัดสิน
  • คะแนนคือ det score 0–1 จาก seg backbone เดียวกันทุก head (extract_feat ครั้งเดียวต่อภาพ)
  • ชุดนี้เป็น development diagnostics ตามหัวไฟล์ eval_det_diagnostics.py ไม่ใช่ชุดตัดสิน production threshold

1. Accuracy รายเวอร์ชันบน testcases 165 ภาพ

เรียงจากดีไปแย่ (threshold 0.5) ภาพจริง 45 + ภาพดัดแปลง 120

2. Specificity เทียบ Recall รายเวอร์ชัน

specificity = ไม่ false alarm บนภาพจริง, recall = จับภาพดัดแปลงได้

3. Accuracy รายหมวด

เห็นว่าหมวดไหนเป็นจุดอ่อนของแต่ละ head (หมวด authentic คือภาพจริง 15 ภาพ)

4. ภาพจริงนอกชุดเทรน รายเวอร์ชัน

camera9 คือสัญญาณหลัก (n=9) ส่วน chatshot2 มีแค่ 2 ภาพ ดูแนวโน้มเท่านั้น

5. คะแนนเฉลี่ยแยกฝั่ง รายเวอร์ชัน

คำนวณจากคะแนนรายภาพจริงใน CSV ไม่ใช่ค่าประมาณ

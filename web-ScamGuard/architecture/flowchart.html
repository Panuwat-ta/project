คำอธิบาย User Flow

  1. เริ่มต้น (Start): ผู้ใช้เข้าสู่แอปพลิเคชัน
  2. หน้าแรก (Home): แสดงเมนูหลัก
  3. นำเข้าภาพ (Import): เลือกรูปภาพที่น่าสงสัยจากคลังภาพ (Gallery) เพื่อเตรียมอัปโหลด
  4. ปรับแต่ง (Edit): Crop หรือปรับขนาดภาพก่อนส่ง (PNG)
  5. ตรวจสอบ (Check): กดปุ่มตรวจสอบเพื่อส่งข้อมูล
  6. ประมวลผล (Processing): อัปโหลดภาพไปยังระบบจัดเก็บคลาวด์ (Cloud Storage) และเข้าสู่กระบวนการวิเคราะห์ System Logic
  7. ผลลัพธ์ (Result):
  8. สำเร็จ: แสดงคะแนนความเสี่ยง (Risk Score) และหลักฐาน (Evidence) จากนั้น Auto-Save ลงฐานข้อมูล
  9. ล้มเหลว: แจ้งเตือนข้อผิดพลาด และให้ทางเลือก (ลองใหม่ หรือ ยกเลิก)
  10. Action: ผู้ใช้เลือกแชร์ผลลัพธ์ หรือจบการทำงาน

คำอธิบาย System Logic

  1. Input: รับไฟล์รูปภาพจากระบบคลาวด์สตอเรจ (Cloud Storage)
  2. Validation: ตรวจสอบว่าไฟล์รูปภาพถูกต้องหรือไม่
  3. หากเสีย/ไม่ใช่รูป: Reject คืนค่า Error
  4. หากถูกต้อง: ส่งไป Preprocessing
  5. Preprocessing: ปรับขนาด (Resize) และ Normalize ภาพ
  6. Caching: ตรวจสอบ Hash ใน Redis
  7. Hit: เคยตรวจแล้ว ให้ดึงผลเก่าจาก Database ส่งคืนทันที
  8. Miss: ไม่เคยตรวจ ให้เข้าสู่ Pipeline การตรวจสอบ
  9. Analysis Tasks:
  10. Task 1 Metadata: ดึงข้อมูล EXIF/GPS
  11. Task 2 OCR: อ่านข้อความในภาพ
  12. Task 3 Forgery: ตรวจสอบการตัดต่อ (Semantic Segmentation)
  13. Partial Failure: ดักจับกรณี Timeout
  14. Keyword Check: ตรวจสอบคำเสี่ยงสูง
  15. Task 4 Source: ค้นหาที่มาของภาพ
    • หากพบน้อย (<=1): ความเสี่ยงต่ำ ส่งไปตรวจ AI-Gen (Task 5)
    • หากพบมาก (>=3): ความเสี่ยงสูง
  16. Scoring: คำนวณคะแนน Weighted Risk Score จากผลลัพธ์ทุกส่วน
  17. Output: สร้างคำอธิบาย บันทึกลง Database และส่ง JSON กลับ Client

ศูนย์เอกสาร ScamGuard: รู้ก่อนเชื่อ ก่อนโอน

ScamGuard คือแอปตรวจสอบรูปภาพด้วย AI หลายชั้น ตั้งแต่สลิปโอนเงิน โปรไฟล์ปลอม สกรีนช็อตแชท ไปจนถึงภาพที่สร้างด้วย AI หน้านี้รวมทุกอย่างตั้งแต่เริ่มต้นใช้งาน วิธีอ่านคะแนนความเสี่ยง และสถาปัตยกรรมระบบ (ย่อจาก wiki/overview.md)

เริ่มใช้งานใน 3 ขั้นตอน

เลือกภาพจากคลังในแอป Android ส่งตรวจ แล้วอ่านผลพร้อม Heatmap — ไม่ต้องถ่ายจากกล้องใน v1 และถ้าเคยตรวจภาพเดียวกัน ระบบตอบจาก Cache ภายในไม่กี่วินาที

1

เลือกรูปจากคลังภาพ

สลิปโอนเงิน โปรไฟล์ สกรีนช็อตแชท หรือเอกสารน่าสงสัย — รองรับไฟล์ภาพทั่วไปจากแกลเลอรี

2

ส่งตรวจ 3 ชั้นอัตโนมัติ

OCR ข้อความ ตรวจสอบแหล่งที่มา และ SegFormer สแกนความผิดปกติของภาพพร้อมกัน

3

อ่านคะแนน + Heatmap

ดู Overall Risk Score 0–100 พร้อมแผนที่ความร้อนชี้จุดดัดแปลงบนภาพจริง วิธีอ่าน Heatmap

การวิเคราะห์หลายชั้น

แต่ละชั้นให้คะแนนอิสระ 0–100 แล้วรวมเป็นคะแนนภาพรวมด้วยหลัก Maximum Impact (มิติที่เสี่ยงที่สุดเป็นฐาน) บวก Multi-Factor Compounding เมื่อหลายมิติเสี่ยงพร้อมกัน รายละเอียดใน wiki/concepts/multi-layer-analysis.md

ชั้นที่ 1 — วิเคราะห์ข้อความ (OCR + NLP)

อ่านข้อความในภาพด้วย Surya OCR แล้วตรวจภาษาหลอกลวง เช่น เร่งให้โอน อ้างรางวัล เลขบัญชีผิดปกติ

คะแนนข้อความ: 0–100

ชั้นที่ 2 — ตรวจสอบแหล่งที่มา

ค้นย้อนว่าภาพนี้เคยปรากฏที่ไหนมาก่อนหรือไม่ สถานะ v1: unavailable (ยังไม่ต่อ Vision API จริง) จึงคำนวณจากมิติที่สำเร็จเท่านั้น

สถานะ v1: unavailable

ชั้นที่ 3 — ภาพผิดปกติด้วย AI (SegFormer)

โมเดลสแกนร่องรอยตัดต่อทั้งภาพ แล้วซ้อน Heatmap ลงบนภาพจริงเพื่อให้เห็นว่าจุดไหนน่าสงสัย

คะแนนภาพ: 0–100

คะแนนความเสี่ยง 3 ระดับ

ไม่มีระดับ Safe — ภาพทุกใบมีคะแนนกำกับ หลักการ: มิติที่เสี่ยงที่สุดกำหนดฐาน แล้วบวกเพิ่มเมื่อหลายมิติเสี่ยงพร้อมกัน (อ่านวิธีคำนวณฉบับเต็ม)

ระดับช่วงคะแนนแปลผลและสิ่งที่ควรทำ
Low0–39ไม่พบสัญญาณชัดเจน ตรวจสอบเบื้องต้นตามปกติก่อนทำธุรกรรม
Medium40–69มีจุดน่าสงสัยบางส่วน ควรตรวจสอบเพิ่ม เช่น ขอหลักฐานอื่น หรือยืนยันตัวตนผู้ส่ง
High70–100พบสัญญาณหลอกลวงชัดเจน หยุดธุรกรรมทันที เก็บหลักฐาน แล้วรายงาน

อ่าน Heatmap ให้เป็นใน 30 วินาที

สีเข้ม = โมเดลมั่นใจว่าบริเวณนั้นผิดปกติ ดูควบคู่กับคำอธิบายจุดน่าสงสัยเสมอ เพราะแสง เงา หรือการบีบอัดไฟล์ก็ทำให้เกิดสัญญาณรบกวนได้

  1. มองภาพรวมก่อน — จุดสีเข้มกระจุกตรงข้อความสำคัญ (ยอดเงิน ชื่อบัญชี) น่าเชื่อถือกว่าจุดกระจายทั่วภาพ
  2. เทียบกับต้นฉบับ — สลับดูภาพจริงกับภาพซ้อน Heatmap ว่าจุดที่ฟ้องตรงกับรอยต่อ ตัวอักษร หรือขอบที่ผิดธรรมชาติหรือไม่
  3. อ่านคำอธิบายประกอบ — ผลตรวจแต่ละชั้นบอกเหตุผลเป็นข้อ ๆ อย่าตัดสินจากสีเพียงอย่างเดียว

สถาปัตยกรรมแบบ Cloud-Native

Flutter (Android) ส่งภาพ → FastAPI Orchestrator กระจายงาน → AI Inference (SegFormer, Surya OCR) → เก็บผลใน PostgreSQL + Cache ด้วย Redis ตาม image_hash ส่วนแอดมินดูภาพรวมผ่าน Admin Portal (React)

คำถามพบบ่อย

ต้องถ่ายรูปจากกล้องได้ไหม

v1 รองรับการเลือกภาพจากคลังภาพเท่านั้น ยังไม่รองรับการถ่ายจากกล้องโดยตรง

ทำไมบางครั้งขึ้น source_status = "unavailable"

เพราะ v1 ยังไม่เชื่อมต่อ Google Vision API จริง ระบบจึงคำนวณคะแนนจากมิติที่วิเคราะห์สำเร็จเท่านั้น ไม่ได้แปลว่าภาพปลอดภัย

ภาพเดิมตรวจซ้ำเร็วแค่ไหน

ภาพที่เคยตรวจแล้ว (ตรง image_hash เดิม) จะตอบจาก Redis Cache โดยเป้าหมาย P95 ไม่เกิน 3 วินาทีสำหรับภาพ 1080p บน 4G/Wi-Fi

ข้อมูลภาพของฉันถูกเก็บไหม (PDPA)

ระบบจะจัดเก็บหรือนำภาพไปปรับปรุงโมเดลก็ต่อเมื่อคุณให้ความยินยอมก่อนเท่านั้น และจัดการสิทธิ์ความเป็นส่วนตัวได้ในแอป

คะแนน Medium ควรทำอย่างไร

อย่าเพิ่งโอน ขอหลักฐานเพิ่มเติม โทรยืนยันผู้รับผ่านช่องทางที่เชื่อถือได้ และตรวจภาพอื่นประกอบ (เช่น แชทต้นทาง)

พร้อมตรวจภาพแรกแล้วหรือยัง

เริ่มจากภาพรวมระบบ แล้วค่อยลงลึกทีละชั้นตามสารบัญด้านข้าง
